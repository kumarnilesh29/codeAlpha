# Books Data Analytics Dashboard

## Project Overview
This project analyzes a dataset of 1,000 books to explore book prices, ratings, and price ranges using data visualization and an interactive dashboard.

## Objectives
- Analyze book prices and ratings.
- Compare average prices across different ratings.
- Identify the most expensive books.
- Present key metrics through dashboard visualizations.

## Tools & Technologies
- Microsoft Power BI
- Python (if used in data collection or preparation)
- HTML, CSS, JavaScript
- CSV Dataset

## Dashboard Features
- Total Books
- Average Price
- Average Rating
- Maximum Price
- Books by Rating
- Average Price by Rating
- Books by Price Range
- Price vs. Rating Analysis
- Top 5 Most Expensive Books
- Interactive filters for ratings, price range, and availability

## Dataset
The dataset contains book titles, prices, ratings, availability, product URLs, and price ranges.

## Project Files
- `Book Data Analytics.pbix` — Power BI report
- `Books_Data_Analytics_Dashboard.html` — HTML dashboard
- `books_dataset_with_price_range.csv` — Dataset
- `Analytics Dashboard.png` — Dashboard screenshot
- `index.html` — Web version of the dashboard

## How to Use
1. Download or clone this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Open `index.html` in a browser to view the HTML dashboard.

## Project Purpose
This project demonstrates practical data analytics, dashboard development, and data visualization skills.
