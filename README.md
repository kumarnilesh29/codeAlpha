# codeAlpha
Interactive Books Data Analytics Dashboard using Power BI
📚 Books Data Analytics Dashboard
An interactive data analytics project built using Power BI and HTML to explore book prices, ratings, and availability.

📊 Project Overview
This project analyzes a dataset of 1,000 books to identify pricing patterns and rating distributions through interactive visualizations.

🛠️ Tools & Technologies
Power BI
HTML, CSS & JavaScript
CSV Dataset
Data Cleaning and Visualization
📈 Dashboard Features
Total Books, Average Price, Average Rating, and Maximum Price KPIs
Books by Rating
Average Price by Rating
Books by Price Range
Top 5 Most Expensive Books
Price vs. Rating Scatter Plot
Interactive filters for rating, price range, and availability
📁 Project Files
Book Data Analytics.pbix — Power BI report
Books_Data_Analytics_Dashboard.html — HTML dashboard
books_dataset_with_price_range.csv — Dataset
Analytics Dashboard.png — Dashboard screenshot
🎯 Objective
To practice data analysis and visualization and present insights in an interactive, easy-to-understand dashboard.
